# NPCs

La base de NPCs usa `Npc`, `NpcRegistry`, `NpcConfig`, `npcId`, `NpcBehavior` y el adaptador `toNpcInteractable` para mantener identidad, creación, comportamiento, interacción y ciclo de vida separados de las escenas. La Oficina AFF incorpora inicialmente al empleado `aff-clerk` como placeholder geométrico visible; no depende de una textura faltante ni bloquea al jugador.

Los comportamientos de scribe y messenger quedan para una iteración posterior con assets propios.
